# TorchGlow

TorchGlow enables real-time, distributed data processing with auto-scaling capabilities, built on a scalable data engine platform.

TorchGlow is built to be simple and practical, focusing on doing one thing well.

**Why TorchGlow?**

- TorchGlow enables real-time, distributed data
- processing with auto-scaling capabilities, built
- on a scalable data engine

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/TorchGlow.git`
2. `cd TorchGlow`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TorchGlow, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
